# Test documents

Almost everything here is made up, and generated by `tests/make_import_samples.py`.

The exception is `kf8_frankenstein.azw3`, because nothing in this project can write the KF8 format. It's *Frankenstein* by Mary Shelley, from Project Gutenberg (https://www.gutenberg.org/ebooks/84). The book is in the public domain in the United States, and this file includes the Project Gutenberg License under which it's distributed.

These files are stored exactly as they are, because tests depend on their exact bytes. Don't regenerate them all to add one: write only the new file.
