# Test documents

Almost everything here is made up, and generated by `tests/make_import_samples.py`.

The exception is `kf8_frankenstein.azw3`, because nothing in this project can write the KF8 format. It's *Frankenstein* by Mary Shelley, from Project Gutenberg (https://www.gutenberg.org/ebooks/84). The book is in the public domain in the United States, and this file includes the Project Gutenberg License under which it's distributed.

Two samples for PDF copies are made by `make_import_samples.py` with tools of their own:

- `pdf_copy_links.epub` is a short made-up book with a link within it, a link out to `example.org`, a `javascript:` link that a copy must leave out, and a nested table of contents. It's written by `pdf_copy_links_epub`.
- `bitonal.djvu` is a black and white page at 300 dpi, as scanned books often are, with bars where lines of type would be. `bitonal_djvu` draws it as a PBM, compresses it with DjVuLibre's `cjb2 -dpi 300`, then adds hidden text (one word of it Greek) and a table of contents with `djvused`. MSYS2's `djvulibre` package has both tools.

These files are stored exactly as they are, because tests depend on their exact bytes. Don't regenerate them all to add one: write only the new file.
