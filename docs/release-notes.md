Papertrail 1.0.1, a library manager and reader for academic publications, for Windows and Linux.

## What's changed

- The reader's Notes panel now shows a highlight's words and its note apart. The page is small and dimmed, the highlighted words are dimmed beside a bar in the highlight's colour, and the note is in full-strength text in a box of its own, with a line between entries. Before, all three looked the same, which made notes hard to read.

## Downloads

| File | For |
|---|---|
| `Papertrail-1.0.1-setup.exe` | Windows 10 and 11. Installs just for you, or for everyone |
| `Papertrail-1.0.1-portable.zip` | Windows 10 and 11, from any folder or a USB stick, keeping its library beside it |
| `Papertrail-1.0.1-x86_64.AppImage` | Most Linux distros, from Ubuntu 22.04 and Debian 12 on |
| `Papertrail-1.0.1.flatpak` | Any Linux distro with Flatpak. Installs the KDE runtime from Flathub |
| `SHA256SUMS` | Checking a download is the one published |

The Windows downloads aren't code-signed, so Windows may say "Windows protected your PC" the first time. Choose **More info**, then **Run anyway**.

See the [README](https://github.com/hachigodesu/Papertrail#readme) for how to install it and what it sends online.
